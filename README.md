##Global Adventures Travel Co. - Introductory HTML Project
This is a single-file HTML document designed to demonstrate fundamental web development concepts, including HTML5 structure, semantic elements, and basic CSS styling, as requested for a class assignment.

The website simulates a simple landing page for an adventure travel company, "Global Adventures Travel Co."

Key Features Demonstrated
This project successfully implements the following core HTML and CSS requirements:

HTML5 Boilerplate: Correct use of <!DOCTYPE html>, <head>, and <body>.

Headings (<h1> to <h3>): Used to define the document structure and hierarchy.

Text Formatting: Demonstrates the use of text-level semantics, specifically:

Bold (<b>)

Italic (<i>)

<u>Underline</u> (<u>)

<del>Strikethrough</del> (<del>)

Lists: Includes three types of lists:

Unordered List (<ul>) for destination features.

Ordered List (<ol>) for the sample itinerary steps.

Definition List (<dl>) for key travel terms.

Table (<table>): A responsive table is used to display structured pricing and package information.

Hyperlinks: Features both internal navigation (using #id links) and external links with target="_blank".

Images (<img>): Two placeholder images are included to represent a destination and an activity.

Internal Styling: Basic CSS is embedded in the <style> block to enhance readability, ensure responsiveness (using max-width and media queries implicitly via fluid design), and apply modern aesthetics like rounded corners and subtle shadows.

File Structure & Sections
The content is organized into logical, semantic HTML5 sections:

Header: Contains the main titles and a navigation menu (<nav>) with internal links.

About Our Mission: Introduces the company and showcases the required text formatting.

Featured Destinations: Details the Patagonian destination using an unordered list.

Sample Activity Itinerary: Describes the Amazon kayaking trip using an ordered list.

Key Travel Terms: Uses a definition list to explain important vocabulary.

Pricing & Booking: Displays travel packages in a tabular format.

Footer: Contains contact information and a "Back to Top" link.
